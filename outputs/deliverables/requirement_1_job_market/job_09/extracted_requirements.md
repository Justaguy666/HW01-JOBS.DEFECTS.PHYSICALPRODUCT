# Extracted Requirements - Job 09

## Role Summary

The role requires a QA Tester at junior, senior, or leader level for ERP and complex business systems, including API testing, SQL/NoSQL validation, automation, AI feature testing, and release quality control.

## Testing Responsibilities

- Lead or coordinate manual and automation QA activities to meet release timelines and quality targets.
- Analyze requirements, review specifications, and clarify business logic with BA, PO, PM, and development teams.
- Build test strategy and test plans across the product lifecycle using risk-based testing.
- Design and manage test cases for complex business flows and end-to-end testing across multiple modules or systems.
- Execute and supervise functional, regression, API, integration, and UAT support testing.
- Test system integration involving APIs, batch jobs, message queues, middleware, or API gateways.
- Integrate automated testing into CI/CD pipelines and maintain stable regression suites.
- Review test cases, test results, test reports, defect lifecycle, and release quality.
- Test migration or data migration work through reconciliation and integrity checks.

## Technical Skills

- ERP or complex enterprise system testing.
- API testing with tools such as Postman or Swagger.
- SQL and NoSQL data validation.
- Automation framework design, test suite management, and test script development.
- Jira or equivalent work/test management and defect reporting tools.
- Git and Docker are advantages.

## AI-Related Requirements

- Develop or improve automation frameworks with AI support.
- Test AI features using datasets, test scenarios, model-version quality tracking, and defined output evaluation criteria.
- Preferred experience using AI for test case design and output quality evaluation while considering data, privacy, and security.

## Experience and Qualifications

- University degree in Information Technology or a related field.
- 3+ years of QA/Tester experience.
- Senior or Lead experience with team coordination is required for higher-level candidates.
- Good problem analysis, cross-team communication, proactivity, and ownership.
