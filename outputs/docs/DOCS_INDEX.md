## Purpose

This document is the navigation index for all project guidance stored under `outputs/docs`.

Goals:

* Make project documentation easy to locate
* Separate rules, templates, workflows, notes, and AI guidance
* Support traceability from working notes to final deliverables
* Keep the HW01 process consistent across all requirements
* Make oral defense preparation easier

## Maintenance Rules

* Keep this index updated when adding or renaming documentation files
* Do not duplicate conflicting rules across documents
* Put reusable structures in `templates`
* Put process steps in `workflows`
* Put naming, status, and evidence rules in `conventions`
* Mark AI-assisted drafts as reviewed only after a human check is complete
