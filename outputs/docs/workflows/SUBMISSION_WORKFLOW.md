## Link Verification

Before zipping:

* [ ] GitHub repository link opens

* [ ] Appendix references match actual appendix files

## PDF Review

Check the exported PDF:

* [ ] Main sections appear in correct order
* [ ] Tables are readable
* [ ] Links are visible
* [ ] AI Critique and Mandatory Disclosure are included
* [ ] Self-assessment section is included

## Zip Review

Before submission:

* [ ] Zip filename matches required format
* [ ] Zip opens successfully
* [ ] File count is within Moodle limit
* [ ] File sizes are within Moodle limit
* [ ] No temp drafts are included
* [ ] No unrelated private files are included

## Final Notes

Final packaging should be mechanical, not creative. If the structure and evidence were maintained during the project, the submission step should only verify and package completed artifacts.
