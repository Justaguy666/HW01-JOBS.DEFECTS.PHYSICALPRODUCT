## Purpose

This document defines the overall workflow for completing HW01 from setup to submission.

Goals:

* Sequence the work across all three requirements
* Prevent evidence and AI-compliance gaps
* Encourage frequent review and commits
* Keep final packaging simple
* Prepare for oral defense throughout the project

## Workflow Overview

```text
Read requirements
    ->
Prepare folder structure and conventions
    ->
Collect evidence and sources
    ->
Draft requirement artifacts
    ->
Review AI output and log mistakes
    ->
Verify evidence and traceability
    ->
Write main report and appendices
    ->
Export PDF and package submission
```

## Commit Guidance

Recommended commit points:

